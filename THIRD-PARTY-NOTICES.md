## ExplorerTabUtility

WinTab 的部分源代码派生自 **ExplorerTabUtility**。派生范围主要为早期版本带入的通用数据结构、主题样式资源，以及 Windows Shell / Win32 互操作声明。这些部分保留其原始实现，并依下述 MIT 许可条款分发。

Parts of WinTab's source code are derived from **ExplorerTabUtility**. The derived portions are primarily general-purpose data structures, theme style resources, and Windows Shell / Win32 interop declarations carried over from WinTab's initial version.
