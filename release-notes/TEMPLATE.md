### 安装包
请按系统架构选择对应安装器：
- `WinTab_vX.Y.Z_x64_Setup.exe`：适用于大多数 64 位 Windows 设备
- `WinTab_vX.Y.Z_x86_Setup.exe`：适用于 32 位 Windows 设备
- `WinTab_vX.Y.Z_arm64_Setup.exe`：适用于 Windows on ARM 设备
