### 更新内容

**新增**
- **中键前台打开标签页**：在资源管理器侧边栏（导航窗格）中键点击文件夹时，新开的标签页直接在前台激活，不再停留在后台。默认开启，可在设置界面与托盘菜单中独立开关，不影响合并、复用、双击关闭等其他功能。

**重构**
- **导航中键输入模块**：拆分为低级输入观测、点击配对隔离、原生句柄与 UIA 身份双重关联三层结构，与既有标签合并/复用钩子完全解耦；所有无障碍接口查询均在工作线程完成，绝不在钩子回调内执行。
- **WinAPI 常量集中管理**：鼠标/键盘消息、低级钩子类型、虚拟键码、拖拽阈值等常量统一收敛到 `WinApi`。

**优化**
- **输入路径开销控制**：中键处理同步耗时上限 12ms，超时立即放弃接管并交还资源管理器原生行为；快照后台缓存并按悬停预热，前台切换、键盘输入、滚轮、拖拽及修饰键操作都会取消待处理请求，避免误激活标签页。
- **测试覆盖**：新增 18 项导航中键测试（唯一新增标签关联、竞争标签、UIA 延迟发布、取消与租约生命周期等）与 2 项设置持久化测试；修复测试替身 HWND 在 64 位下被截断为 int 的问题。

### 安装包
请按系统架构选择对应安装器：
- `WinTab_v2.0.5_x64_Setup.exe`：适用于大多数 64 位 Windows 设备
- `WinTab_v2.0.5_x86_Setup.exe`：适用于 32 位 Windows 设备
- `WinTab_v2.0.5_arm64_Setup.exe`：适用于 Windows on ARM 设备
