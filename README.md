# WinTab

Windows 11 文件资源管理器标签页工具

简体中文 | [English](README.en.md)

![Platform](https://img.shields.io/badge/platform-Windows%2011-555555) ![.NET](https://img.shields.io/badge/.NET-9.0-555555) ![License](https://img.shields.io/badge/license-MIT-555555)

</div>

WinTab 把资源管理器的多个窗口收进一个窗口：新打开的窗口自动合并为标签页，相同文件夹复用已有标签，标签组与最近关闭的标签页可随时找回。

---

![](Assets/UI.png)

## 功能

- 一窗多标签：新打开的资源管理器窗口自动合并为当前窗口的标签页
- 复用已有标签页，不重复打开同一文件夹
- 持续保存标签组，关机或资源管理器崩溃后可恢复；最近关闭的标签页也能找回
- 鼠标停在标签栏上滚动滚轮切换前后标签，灵敏度可选低／中／高
- 双击标签页标题直接关闭
- 中键点击侧边栏、文件列表、主页或地址栏中的文件夹时，一律在前台打开
- 「打开文件所在位置」等原生定位落到后台标签时，自动把该标签切到前台
- 按住 `Ctrl + Shift` 打开文件夹可保留独立窗口；把标签拖出标签栏可分出新窗口
- 托盘常驻运行，支持开机启动，可切换深／浅色主题与中英文界面

运行日志默认在后台记录近两天，位于 `%LOCALAPPDATA%\WinTab\logs\`，设置页的「打开日志」可直接打开。

## 恢复上次标签组

WinTab 运行时持续记录标签组，只恢复最近使用的一个窗口：正常关闭保存最后关闭的窗口，关机或崩溃后恢复最后使用窗口的最近记录。「标签组包含单标签窗口」默认关闭，此时仅记录含两个及以上标签的窗口，关闭单标签窗口不覆盖已保存的组；此选项不影响恢复最近关闭的标签页。

托盘的「标签恢复」功能区和设置页均提供：

- **恢复上次标签组**：在新窗口中恢复标签组，保留标签顺序与原活动标签。默认快捷键 `Alt + E`，全局生效
- **恢复上一个标签页**：恢复最近关闭的标签，优先使用当前窗口。默认开启，默认快捷键 `Alt + W`，仅资源管理器前台生效；最近 25 个关闭记录仅保留到本次运行结束。位置已无法打开时（例如网络位置或已拔出的磁盘），自动改为恢复更早一个可打开的标签并提示跳过

两个快捷键都可单独启用或改键，不需要开启自动恢复。关闭「自动恢复上次标签组」只停止自动打开标签组，后台记录、快捷键和恢复按钮不受影响。

单标签快捷键开启时会自动记住最近关闭的标签，不必另开记录开关。关闭快捷键后，可继续保留记录供按钮或托盘恢复；只有快捷键和「记住最近关闭的标签页」都关闭时才停止记录并清空历史。

快捷键支持 `Ctrl` / `Alt` 搭配字母、主键盘数字或 `F1`–`F24`（可加 `Shift`）。路径记录保存在 `%APPDATA%\WinTab\session.json` 及其备份，请按个人文件夹信息保护。

### 自动恢复（可选）

「自动恢复上次标签组」默认关闭。开启后仅在没有其他资源管理器窗口时，由新打开的窗口触发：

- **仅普通启动（默认）**：从主页、此电脑或设定的启动位置启动时恢复
- **打开任意文件夹**：保留最初打开的标签，并在其后补回历史标签

拖出的窗口、`Ctrl + Shift` 独立窗口和开启此功能时已存在的窗口不触发恢复；缺失或不支持的位置会跳过。已在文件夹选项中开启系统的「登录时还原上一个文件夹窗口」时，Windows 会自行还原关机或资源管理器异常结束时仍打开的窗口及其标签，WinTab 不再重复补回同一标签组，仍可通过托盘或快捷键手动恢复。

## 下载

根据 CPU 架构选择对应安装器（[Releases](https://github.com/OUBIGFA/WinTab/releases)）：

- `WinTab_<版本>_x64_Setup.exe` — 64 位 Intel/AMD（大多数用户）
- `WinTab_<版本>_arm64_Setup.exe` — ARM64 Windows（Surface Pro X 等）
- `WinTab_<版本>_x86_Setup.exe` — 32 位 Windows

应用内更新会先用 GitHub 为安装包发布的 SHA-256 校验下载文件，校验不一致时不会运行安装器。

## 系统要求

- Windows 11 22H2 或更高版本
- .NET 9 Desktop Runtime（首次运行安装器会自动下载安装）
